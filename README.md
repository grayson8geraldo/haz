# Natural Gas Futures Trading System

Автоматическая торговая система для фьючерсов на природный газ (NYMEX NG / Micro QG).

## Архитектура

```
┌─────────────────────────────────────────────────────────────┐
│                     Слой данных                              │
│  Рыночные данные  │  EIA Storage  │  Погода/HDD  │  LNG    │
│  NYMEX NG, TTF    │  Еженедельно  │  NOAA, OM    │  EIA    │
└─────────────────────────────┬───────────────────────────────┘
                              │
┌─────────────────────────────▼───────────────────────────────┐
│                   Движок сигналов                            │
│  Тех. анализ  │ Фундаментал │  ML-модель  │  Сезонность    │
│  RSI,VWAP,ATR │ Запасы,HDD  │  XGBoost    │  Calendar      │
└─────────────────────────────┬───────────────────────────────┘
                              │
┌─────────────────────────────▼───────────────────────────────┐
│                   Риск-менеджмент                             │
│  ATR sizing  │  Stop/Target  │  Дневные лимиты  │  EIA KS  │
└─────────────────────────────┬───────────────────────────────┘
                              │
┌──────────────────┬──────────▼──────────┬────────────────────┐
│  Исполнение      │    Мониторинг       │  Бэктестинг        │
│  IBKR / Bracket  │  Telegram / Dash    │  Walk-forward      │
└──────────────────┴─────────────────────┴────────────────────┘
```

## Быстрый старт

```bash
# 1. Установка
pip install -e ".[dev]"

# 2. Конфигурация
cp config/.env.example config/.env
# Заполнить API ключи в .env

# 3. Просмотр статуса
python main.py status

# 4. Бэктест
python main.py backtest

# 5. Оптимизация параметров
python main.py optimize

# 6. Запуск Paper Trading
python main.py trade

# 7. Dashboard
python main.py dashboard
```

## Компоненты

| Модуль | Описание |
|--------|----------|
| `gas_trader/data/` | Источники данных: IBKR, EIA, Open-Meteo |
| `gas_trader/signals/` | Генерация сигналов: тех. анализ, ML, сезонность |
| `gas_trader/risk/` | Управление рисками: ATR sizing, стопы, лимиты |
| `gas_trader/execution/` | Исполнение ордеров: IBKR API, bracket orders |
| `gas_trader/monitoring/` | Мониторинг: Telegram алерты, Streamlit дашборд |
| `gas_trader/backtest/` | Бэктестинг: walk-forward, Optuna оптимизация |

## Важные замечания

- **Начинайте с Paper Trading** — протестируйте систему на виртуальных деньгах
- **Micro-контракт QG** автоматически выбирается при капитале < $3,300
- **EIA Kill Switch** автоматически останавливает торговлю перед/после отчёта EIA
- **Дневные лимиты** защищают от катастрофических потерь
- **Walk-forward анализ** проверяет устойчивость стратегии на out-of-sample данных

## ⚠️ Дисклеймер

Торговля фьючерсами связана с высоким риском потери капитала. Данная система
предоставляется исключительно в образовательных целях. Разработчик не несёт
ответственности за финансовые потери. Всегда проводите собственный анализ и
используйте только те средства, потерю которых вы можете себе позволить.
